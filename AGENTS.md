# AI-first platform

Платформа связывает сотрудников, проекты, агентов и правила компании.

- Требования. Сверяй объём и поведение продукта с [требованиями заказчика](customer-requirements.md) и [согласованными границами первой версии](docs/first-version.md).
- Термины. Используй определения из [словаря проекта](DOMAIN.md).
- Предметная модель. Перед работой с приглашениями, учётными записями, ролями, проектами, назначениями или подключениями Codex, а также при изменении границ модулей прочитай [предметную модель](docs/domain-model.md).
- Права GitHub. При работе над расчётом, выдачей, отзывом или сверкой прав на репозитории прочитай [ADR об ответственности модулей](docs/adr/0001-access-and-github-permissions.md) и [интерфейс сверки](docs/design/github-access-reconciliation.md).
- Скиллы проекта находятся в [`.agents/skills/`](.agents/skills/).
- Задачи ведутся в GitHub Issues. Для работы с ними используй [правила трекера](docs/agents/issue-tracker.md).
