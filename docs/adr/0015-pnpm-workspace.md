# pnpm для приложений монорепозитория

Менеджер пакетов проекта — pnpm. Приложения apps/web и apps/api будут входить в единый workspace. Его состав будет задан в pnpm-workspace.yaml в корне. У приложений будут собственные package.json, а установка зависимостей и общие команды проверки будут доступны из корня.

Рассмотрены npm workspaces и современный Yarn с workspaces. Все варианты подходят для выбранного стека. pnpm выбран для управления двумя приложениями и получения практики работы с этим инструментом. Его стандартная структура установки ограничивает доступ к зависимостям, не объявленным пакетом, и позволяет повторно использовать файлы пакетов в общем хранилище. Это не заменяет проверку архитектурных импортов.

Компромисс — необходимость установить и освоить pnpm. Для среды выбраны Node.js 24 LTS и pnpm 12: [ADR-0020](0020-runtime-versions.md). Точные версии фиксируются при подготовке конфигурации окружения. Настройка workspace и установка зависимостей пока не выполнены.

Источник: [workspaces pnpm](https://pnpm.io/workspaces), [устройство установки pnpm](https://pnpm.io/motivation).
