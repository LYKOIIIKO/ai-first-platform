# Сервисы Docker Compose для локальной разработки

Для основного локального режима первой версии выбран Docker Compose с сервисами web, api, db и rabbitmq. Web запускает Vite и React-приложение, api — NestJS, db — PostgreSQL, rabbitmq — брокер событий. PostgreSQL и RabbitMQ используют отдельные тома для сохранения данных между обычными перезапусками. Изменения исходников frontend и backend должны подхватываться без ручной пересборки при каждом сохранении.

С первой предметной миграцией добавляется одноразовый сервис `migrate`. Он ждёт готовности PostgreSQL и применяет общую историю миграций. API запускается после успешного завершения `migrate` и готовности своих зависимостей. Web по-прежнему запускается независимо. [ADR-0005](0005-drizzle.md).

Единое описание запуска задаёт версии среды и соединения сервисов. Выбор даёт практику работы с контейнерами, их сетью и хранением данных. Компромисс — необходимость работающего Docker и настройки подхвата изменений исходников.

Полный стек запускается с помощью `docker compose up --wait` с конечным `--wait-timeout`. Для разработки предусмотрен Compose Watch. [Проверка полного запуска](0017-local-readiness.md).

Для отладки на компьютере Compose запускает только PostgreSQL и RabbitMQ с ожиданием готовности. Корневая команда `pnpm dev` запускает оба приложения на компьютере с общей инфраструктурой и теми же томами. Этот режим требует поддерживать согласованные версии Node.js и pnpm на компьютере. Когда появятся предметные миграции, перед запуском API в этом режиме выполняется `migrate` в Compose.

При переходе между режимами сначала освобождаются порты web и API. Инфраструктура и её данные сохраняются. Порядок переключения описывается в корневом README.

Проверки готовности определены в [ADR-0017](0017-local-readiness.md), локальные настройки и хранение секретов — в [ADR-0018](0018-local-settings-and-secrets.md), адреса соединений — в [ADR-0019](0019-local-networking.md). Ветки версий среды заданы в [ADR-0020](0020-runtime-versions.md), способ подхвата изменений — в [ADR-0021](0021-compose-watch.md). Точные версии образов фиксируются при подготовке конфигурации. Файлы Compose и образы приложений пока не созданы. Запуск сервисов не проверен.

Источники: [Compose Watch](https://docs.docker.com/compose/how-tos/file-watch/), [сеть Compose](https://docs.docker.com/compose/how-tos/networking/), [порядок запуска](https://docs.docker.com/compose/how-tos/startup-order/).
