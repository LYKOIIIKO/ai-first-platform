# Одна база PostgreSQL с владением данными по модулям

Предметные модули используют одну базу PostgreSQL. У каждой таблицы один модуль-владелец. Он определяет правила чтения и изменения своих данных. Другие модули обращаются к этим данным только через интерфейс владельца. Прямое чтение и изменение чужих таблиц через Drizzle запрещено.

Такое разделение сосредотачивает правила и изменения структуры хранения у владельца данных. Вызывающие модули зависят от согласованного интерфейса, а не от устройства чужих таблиц. Компромисс — необходимость описывать интерфейсы даже для запросов, которые было бы короче выполнить напрямую.

Рассмотрены общие таблицы без закреплённого владельца и отдельная база на каждый модуль. Первый вариант сильнее связывает модули со структурой хранения. Второй усложняет согласованное изменение данных и локальное окружение. Для первой версии выбран один экземпляр базы с разделением ответственности в коде.

Разрешённые зависимости заданы в [ADR-0010](0010-allowed-module-dependencies.md). Конкретные таблицы, физическое разделение схем PostgreSQL и порядок транзакций между модулями определяются отдельно. Наличие интерфейсов само по себе не обеспечивает атомарность действий нескольких модулей.
