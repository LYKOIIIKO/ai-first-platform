# PostgreSQL как основная база данных

Основная база данных платформы — PostgreSQL. Учётные записи, назначения, проекты и репозитории образуют связанную модель. Таблицы, ограничения связей и транзакции подходят для хранения таких данных. Для учебного проекта выбор также даёт практику SQL и работы с отдельным сервисом базы данных.

Рассмотрены SQLite и MongoDB. SQLite упрощает запуск, но даёт меньше практики обслуживания серверной базы. MongoDB допускает разные структуры документов, однако это не устраняет преобразование существующих данных и поддержку старых форматов при изменении модели. Для первой версии преимущества документного хранения не перевешивают пользу таблиц и явных связей.

Компромисс PostgreSQL — необходимость освоить SQL, обслуживание сервиса и миграции структуры базы. Значительные изменения модели потребуют продуманного преобразования данных. Для доступа к базе и миграций выбраны Drizzle ORM и Drizzle Kit: [ADR-0005](0005-drizzle.md). Схема хранения определяется отдельно.
