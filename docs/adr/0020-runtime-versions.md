# Версии среды технического каркаса

Для начальной конфигурации выбраны Node.js 24 LTS, PostgreSQL 18 и pnpm 12. Точные версии выпусков внутри этих веток фиксируются при подготовке конфигурации. Обновление выполняется отдельным изменением с проверками, чтобы среда не менялась незаметно.

Node.js 24 выбран как поддерживаемая LTS-ветка с более длительной практикой использования, чем также доступная Node.js 26 LTS. PostgreSQL 18 является поддерживаемой веткой; внутри неё используется актуальный выпуск с исправлениями. Pnpm 12 выбран как текущая основная ветка менеджера пакетов на момент обсуждения. Компромисс — необходимость отдельно поддерживать зафиксированные версии и проверять их обновления.

Версия pnpm закрепляется в конфигурации проекта, версии зависимостей — в общем lock-файле workspace. Конкретные образы Node.js и PostgreSQL фиксируются при подготовке Docker-конфигурации. Совместимые стабильные версии библиотек выбираются и проверяются на этом же этапе.

На момент проверки компьютера установлен Node.js 20 и pnpm 10. Их обновление не выполнялось. Контейнерная конфигурация и установка выбранных версий пока не подготовлены.

Источники: [ветки Node.js](https://nodejs.org/en/about/previous-releases), [версии PostgreSQL](https://www.postgresql.org/support/versioning/), [установка pnpm](https://pnpm.io/installation).
