# Drizzle ORM и Drizzle Kit для работы с PostgreSQL

Backend использует Drizzle ORM для запросов к PostgreSQL и Drizzle Kit для создания и применения SQL-миграций. Описания таблиц находятся в TypeScript. Типы чтения, добавления и результатов запросов выводятся из этих описаний и выбранных полей.

Выбор соответствует учебной цели проекта: SQL остаётся заметен в запросах, а TypeScript помогает проверять обращения к таблицам. Компромисс — необходимость освоить SQL и правила Drizzle. Генерация миграций не заменяет проектирование преобразований существующих данных.

Рассмотрены Prisma ORM и SQL через node-postgres. Prisma предоставляет собственную модель запросов и инструменты работы со структурой базы. Прямой SQL даёт контроль над запросами, но требует больше ручной работы с типами результатов и отдельного выбора инструментов миграций. Для проекта выбран вариант с запросами, близкими к SQL, и выводом типов из описаний таблиц.

Таблицы принадлежат предметным модулям; другие модули обращаются к ним только через интерфейс владельца: [ADR-0007](0007-module-data-ownership.md). Схема хранения и расположение описаний таблиц определяются отдельно.
