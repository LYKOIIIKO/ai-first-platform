# Feature-Sliced Design для frontend

Frontend в apps/web организуется по Feature-Sliced Design (FSD). Выбор заменяет предложенную упрощённую структуру app, pages и shared. Он соответствует учебной цели проекта и задаёт стандартные правила расположения кода, зависимостей и открытых точек входа.

Для будущего кода выбраны стандартные слои app, pages, widgets, features, entities и shared. Слои и их содержимое будут добавляться по необходимости. Каталоги будущих пользовательских действий и сущностей заранее не создаются. Предусмотренные начальные точки входа — index.html и src/main.tsx; корневой React-компонент будет расположен в слое app. Код frontend пока не создан.

В pages, widgets, features и entities код группируется в слайсы — самостоятельные части по смыслу для приложения. Слайс использует другие слайсы только из нижележащих слоёв. Связи слайсов одного слоя по умолчанию запрещены. Предусмотренные FSD специальные связи сущностей через @x рассматриваются отдельно при появлении конкретной необходимости. App и Shared разделяются на сегменты и не содержат слайсов; их сегменты могут обращаться друг к другу внутри слоя.

Открытая точка входа слайса — index.ts с именованными экспортами. Другие слайсы используют только эту точку входа. Внутренние файлы слайса обращаются друг к другу напрямую, без импорта собственного index.ts. В Shared открытые точки входа определяются для сегментов или отдельных общих компонентов и библиотек; общий index.ts для всего слоя не требуется.

Внутренние сегменты, например ui, api и model, появляются по содержимому кода. Компромисс FSD — необходимость следовать правилам слоёв и поддерживать явные открытые экспорты. Направления импортов и открытые точки входа frontend учитываются при настройке выбранных dependency-cruiser и ESLint. Их конфигурация пока не создана.

Frontend взаимодействует с backend по HTTP и не импортирует исходники apps/api, включая описания таблиц Drizzle. FSD относится к frontend и не изменяет [согласованную структуру backend](0013-backend-layout.md). Пользовательские функции пока не реализуются.

Источники: [слои FSD](https://feature-sliced.design/docs/reference/layers), [слайсы и сегменты](https://feature-sliced.design/docs/reference/slices-segments), [открытые точки входа](https://feature-sliced.design/docs/reference/public-api).
