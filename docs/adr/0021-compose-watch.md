# Compose Watch для изменений исходников

Для локальной разработки выбран Docker Compose Watch. В режиме Watch изменённые исходники синхронизируются с контейнерами. Vite обновляет интерфейс, а NestJS перезапускает backend при изменении его исходников. При изменении состава зависимостей пересобирается соответствующий образ.

Node_modules остаётся внутри контейнеров и не переносится с компьютера. Локальные файлы настроек с секретами, .git и результаты сборки исключаются из синхронизации. Это сохраняет разделение исходников, установленных зависимостей и локальных настроек.

Рассмотрено непосредственное подключение каталогов компьютера через bind mounts. Выбран Watch, чтобы явно задавать переносимые файлы и исключения, в том числе для проекта на Windows. Компромисс — отдельная настройка синхронизации и пересборки. Для подхвата изменений должен работать режим Watch.

Правила Watch пока не созданы. Подхват изменений frontend, перезапуск backend и пересборка при изменении зависимостей требуют практической проверки после подготовки окружения.

Источник: [Compose Watch](https://docs.docker.com/compose/how-tos/file-watch/).
