# Node.js, TypeScript и NestJS для backend

Backend платформы использует Node.js, TypeScript и NestJS. Проект учебный: изучение новых технологий важнее скорости реализации. React и Next.js уже знакомы владельцу, а выбранный стек позволяет изучать серверную разработку в экосистеме JavaScript.

NestJS выбран за явную организацию модулей, их зависимостей и предоставляемых возможностей. Это соответствует потребности платформы в понятных границах частей приложения. Компромисс — дополнительные правила и служебный код фреймворка.

Рассмотрены Fastify без NestJS и серверные возможности Next.js. Fastify оставляет больше решений об устройстве приложения разработчику. Next.js позволяет объединить интерфейс и серверные обработчики, но для учебной цели выбран самостоятельный backend на NestJS.

Для frontend выбраны React, TypeScript и Vite: [ADR-0003](0003-frontend-stack.md). Основная база данных — PostgreSQL: [ADR-0004](0004-postgresql.md). Backend организован как модульный монолит: [ADR-0006](0006-modular-monolith.md). Выбор HTTP-адаптера NestJS остаётся открытым. Разрешённые зависимости предметных модулей, автоматическая проверка границ и надёжное выполнение повторных сверок требуют отдельных решений.
