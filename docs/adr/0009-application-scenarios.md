# Прикладные сценарии для координации предметных модулей

Сквозные действия первой версии координируют отдельные прикладные сценарии над пятью предметными модулями. Сценарий задаёт порядок вызовов интерфейсов, получает результаты и обрабатывает ошибки. Правила доступа, состав проектов, состояние сотрудников и подключений остаются ответственностью соответствующих модулей.

Такое разделение позволяет избежать взаимных зависимостей. Например, при выдаче инструкций сценарий получает решение «Доступа», а затем содержимое у «Проектов». Для расчёта прав «Доступ» получает сведения о составе проекта через интерфейс «Проектов». Обратный вызов из «Проектов» в «Доступ» для этого не требуется.

Рассмотрена координация сквозных действий внутри предметных модулей с взаимными вызовами. Выбран отдельный прикладной слой, чтобы сохранить направленные зависимости и явный порядок действий. Компромисс — дополнительный код координации. Каждый сценарий отвечает за своё действие; слой не должен дублировать правила модулей или объединять всю логику в одном месте.

Управление сверкой и повторами прав GitHub остаётся в «Доступе» согласно [ADR-0001](0001-access-and-github-permissions.md). Требование проверять актуальность прав перед отправкой ответа Codex сохраняется. Разрешённые зависимости заданы в [ADR-0010](0010-allowed-module-dependencies.md). Порядок транзакций и механизм проверки прав при изменениях во время запроса определяются отдельно.
