# Один репозиторий с приложениями web и api

Для frontend и backend первой версии выбран один репозиторий. Каталог apps/web предназначен для React-приложения на TypeScript с Vite. Каталог apps/api предназначен для backend на Node.js, TypeScript и NestJS. Документы проекта остаются в docs и в существующих файлах корня. Каталоги приложений пока не созданы.

У каждого приложения будут собственные зависимости, настройки и команды запуска. Общие команды проверки будут доступны из корня репозитория. Изменения интерфейса, backend и документации можно будет согласовать в одном pull request.

Рассмотрено размещение приложений в разных репозиториях. Для личного учебного проекта выбран один репозиторий, чтобы держать совместные изменения и архитектурные правила рядом. Компромисс — необходимость настроить совместную работу двух приложений в одном репозитории.

Общие пакеты выделяются при появлении конкретного кода для совместного использования. Каталоги backend и точки входа предметных модулей определены в [ADR-0013](0013-backend-layout.md). Для структуры frontend выбрана FSD: [ADR-0014](0014-frontend-fsd.md). Для управления приложениями выбран workspace pnpm: [ADR-0015](0015-pnpm-workspace.md). Это решение описывает размещение кода и не меняет выбранный модульный монолит backend.
