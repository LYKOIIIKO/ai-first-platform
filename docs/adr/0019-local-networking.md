# Адреса сервисов и проксирование локальных запросов

После подготовки и запуска окружения интерфейс будет открываться по адресу http://localhost:5173. Браузер будет отправлять запросы backend на относительные пути /api/ того же адреса. Сервер Vite будет пересылать их на http://api:3000, удаляя префикс /api. Например, /api/health/ready должен пересылаться на http://api:3000/health/ready.

Внутри сети Compose backend будет подключаться к PostgreSQL по адресу db:5432. Для сервисов предусмотрены имена api и db; localhost внутри контейнера означает сам этот контейнер. После запуска для прямой отладки backend будет доступен с компьютера по адресу http://localhost:3000, а PostgreSQL — по адресу localhost:5432.

Опубликованные порты 5173, 3000 и 5432 привязываются к 127.0.0.1 на компьютере. Внешние номера портов можно менять через локальный .env. Внутренние адреса сервисов сохраняются независимо от изменения опубликованных портов.

Рассмотрены прямые запросы браузера к отдельному адресу backend. Выбрано проксирование через Vite, чтобы интерфейс использовал относительные адреса запросов. Компромисс — дополнительная настройка прокси. Публикация api и db на локальном компьютере даёт прямой доступ для отладки и работы с базой.

Решение относится к локальной разработке. Конфигурация и соединения пока не проверены на запущенных сервисах.

Источники: [сеть Compose](https://docs.docker.com/compose/how-tos/networking/), [прокси Vite](https://vite.dev/config/server-options.html#server-proxy).
